# NOVA GPT 会员商城（独立第三方模板）

这是一个可本地运行、可部署到支持 Node.js 持久化磁盘的服务器的全栈商城起始项目。包含四档月付方案、响应式页面、明暗主题、邮箱注册/登录、订单记录、管理员后台、套餐价格编辑、人工订单核验，以及支付宝/微信二维码展示。

## 重要合规说明
- 本项目默认 `PAYMENT_ENABLED=false`，因此默认不能创建支付订单，也不会展示收款码。不要在未确认收款主体、经营资格、服务来源、退款规则及适用法律前开启收款。
- 这只是独立第三方商城模板，不代表 OpenAI 授权经销商，不得暗示官方合作或保证 OpenAI 账号权益。只有在你确实有权提供所售服务时才可上线销售。
- 不得要求客户提供 ChatGPT 密码、验证码或恢复代码。
- 价格是你提供的初始展示值，不是实时官方报价。上线前必须核实官方当前价格、额度与服务条款，并在页面明确说明实际交付内容。
- 管理员将订单改为“已核验”代表人工核对到账；程序不会连接支付机构，也不会自动验证付款。二维码只作为收款入口，不是支付接口。
- 如果经营者未达到当地签约/收款年龄要求，应由监护人或合规经营主体负责账户、合同、税务和收款事宜。

## 环境要求
- Node.js 20+
- npm
- 可写入本地 `data/` 目录的持久化磁盘（SQLite 数据库和会话存储）

## 本地运行
```bash
cp .env.example .env
```
编辑 `.env`，至少修改：
- `SESSION_SECRET`：长随机字符串
- `ADMIN_EMAIL`：管理员邮箱
- `ADMIN_PASSWORD`：强管理员密码（首次启动时创建管理员）
- `PAYMENT_ENABLED=false`：保持关闭，完成核验后才考虑开启

然后：
```bash
npm install
npm start
```
打开 http://localhost:3000

## 部署
部署到支持 Node.js 长期运行和持久化磁盘的 VPS/应用平台：
1. 上传项目或连接 Git 仓库。
2. 设置启动命令 `npm start`，Node 版本 20 或更高。
3. 配置上述环境变量，生产环境设置 `COOKIE_SECURE=true` 并启用 HTTPS。
4. 为 `data/` 配置持久化磁盘，否则重启/重新部署可能丢失数据库和会话。
5. 首次启动后使用管理员邮箱登录，在后台管理套餐、公告和订单。
6. 默认不要开启收款。确认有权经营、收款账户与二维码归属正确、服务可合法交付后，再设置 `PAYMENT_ENABLED=true`。

## 支付二维码
`public/assets/alipay.png` 和 `public/assets/wechatpay.png` 是从你提供的两张图片中读取二维码内容后重新生成的纯黑白高清二维码。重新生成后的二维码内容与原码解析出的支付链接一致；仍建议用支付宝/微信分别实际扫码验证，并确认收款方名称、金额与用途正确。
